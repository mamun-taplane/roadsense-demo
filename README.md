# Road Sense — review demo

Live demo of Road Sense (Connected Utah / UDOT V2X).
- Map app, live Mapbox map: https://mamun-taplane.github.io/roadsense-demo/
- No-map app (cluster): https://mamun-taplane.github.io/roadsense-demo/cluster/
- Feature designs (left "Features" menu): e.g. https://mamun-taplane.github.io/roadsense-demo/features/car-alerts/
The bar at the top switches app, device and brand (Connected Utah, RoadSense, Derq). Demo controls (screen size, who you are, play, speed,
jump to scenes) are in a right pane: open on a computer (hide / show), "Controls" on a phone.
Screen size: 100% (real size, scroll; default on a computer) or Fit to window.

Built from the private design repo by `tools/demo/build.sh`. Don't edit here; changes are overwritten.
