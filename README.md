# Road Sense — review demo

Live demo of Road Sense (Connected Utah / UDOT V2X).
- Map app, live Mapbox map: https://mamun-taplane.github.io/roadsense-demo/
- No-map app (cluster): https://mamun-taplane.github.io/roadsense-demo/cluster/
The bar at the top switches between them. On a phone you see the app; on a computer also a side
panel (play, speed, jump to scenes).

Built from the private design repo by `tools/demo/build.sh`. Don't edit here; changes are overwritten.
